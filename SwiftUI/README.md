# SwiftUI Projects Collection

**Набор учебных проектов на SwiftUI для освоения iOS-разработки**

---

## Список проектов

### 1. [WeSplit](/SwiftUI/WeSplit)
Практичное приложение для разделения счета в ресторане с учетом чаевых и количества человек.

### 2. [Convector](/SwiftUI/Convector)
Утилита для конвертации временных единиц измерения с простым и понятным интерфейсом.

### 3. [Guess the Flag](/SwiftUI/Guess%20the%20Flag)
Обучающая игра для изучения флагов стран мира с интерактивным интерфейсом.

### 4. [Rock-Scissors-Paper](/SwiftUI/Rock-Scissors-Paper)
Интерактивная игра для тренировки когнитивных навыков на основе классической игры "Камень, Ножницы, Бумага" с элементами стратегического мышления.

### 5. [BetterRest](/SwiftUI/BetterRest)
Интеллектуальное приложение для расчета оптимального времени отхода ко сну с использованием машинного обучения Core ML.

### 6. [WordScramble](/SwiftUI/WordScramble)
Увлекательная словесная игра для развития словарного запаса и лингвистического мышления с механикой составления слов из ограниченного набора букв.

### 7. [MultiplyMaster](/SwiftUI/MultiplyMaster)
Обучающее приложение для детей для изучения таблицы умножения с игровым подходом к обучению.

### 8. [iExpense](/SwiftUI/iExpense)
Приложение для раздельного учета личных и деловых расходов с возможностью добавления, удаления и сохранения финансовых операций.

### 9. [Moonshot](/SwiftUI/Moonshot)
Интерактивное приложение для изучения миссий NASA «Аполлон» и биографий астронавтов с детальной информацией о космической программе.

### 10. [HabitTracker](/SwiftUI/HabitTracker)
Персональный трекер привычек для отслеживания регулярной активности с функцией сохранения прогресса и детальной статистикой.

### 11. [CupcakeCorner](/SwiftUI/CupcakeCorner)
Приложение для заказа капкейков с многоэкранным интерфейсом, возможностью онлайн-оформления заказов и проверкой данных форм.

### 12. [Bookworm](/SwiftUI/Bookworm)
Персональный дневник чтения для учета прочитанных книг с системой рейтингов и рецензий на основе SwiftData.

### 13. [InstaFilter](/SwiftUI/Instafilter)
Приложение для импорта и профессиональной обработки фотографий с использованием фреймворков Core Image и UIKit.

### 14. [BucketList](/SwiftUI/BucketList)
Приложение для создания личного списка мест с использованием карт MapKit, поиска локаций и защищенного хранения данных с биометрической аутентификацией.
### 15. [MemoryFaces](/SwiftUI/MemoryFaces)
Приложение для создания визуальной базы контактов с импортом фотографий и хранением полной информации о людях в SwiftData.

### 16. [HotProspects](/SwiftUI/HotProspects)
Приложение для цифрового нетворкинга на конференциях с функцией обмена контактами через QR-коды, системой сортировки и локальными уведомлениями.

### 17. [Flashzilla](/SwiftUI/Flashzilla)
Интерактивное приложение для обучения по системе карточек (flashcards) с использованием жестов, таймеров и хранением данных в SwiftData.

### 18. [DiceRoll](/SwiftUI/DiceRoll)
Приложение для броска двух виртуальных кубиков с эффектом постепенной смены значений и тактильной обратной связью.

# iOS Development Projects

**Коллекция учебных проектов для освоения iOS-разработки на SwiftUI и UIKit**

---

## 📂 Структура репозитория

### 🎨 [SwiftUI](./SwiftUI)
Проекты, созданные с использованием современного декларативного фреймворка SwiftUI.

### 🏗 [UIKit](./UIKit)
Проекты, созданные с использованием классического императивного фреймворка UIKit.

---

## 🛠 Технологии

- **SwiftUI** — современный declarative UI фреймворк
- **UIKit** — классический фреймворк для построения интерфейсов
- **Swift** — основной язык разработки
- **Core ML** — машинное обучение
- **SwiftData** — работа с базами данных
- **MapKit** — интеграция карт
- **Core Image** — обработка изображений
- **iOS 15.0+** — целевая платформа

---

## 📚 Цель проектов

Этот репозиторий содержит коллекцию учебных проектов, созданных для освоения различных аспектов iOS-разработки:
- Работа с пользовательским интерфейсом
- Интеграция машинного обучения
- Создание игровой логики
- Работа с различными фреймворками Apple
- Изучение различий между SwiftUI и UIKit

---

## 🚀 Как использовать

1. Клонируйте репозиторий
2. Перейдите в папку с нужным фреймворком (SwiftUI или UIKit)
3. Откройте интересующий проект в Xcode
4. Запустите на симуляторе или устройстве
